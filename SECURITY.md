# Security policy

## Supported versions

Only the latest release receives security fixes.

## Reporting a vulnerability

Please **do not open a public issue** for security problems.

Report them privately through
[GitHub private vulnerability reporting](https://github.com/076923/cv2-utils/security/advisories/new),
or by email to s076923@gmail.com.

Include a description of the issue, the affected version, and steps or a minimal example to reproduce it.
You should receive a response within 7 days. Once a fix is released, the advisory will be published with credit
to the reporter unless you prefer to stay anonymous.

Note that vulnerabilities in OpenCV itself should be reported to the
[OpenCV project](https://github.com/opencv/opencv/security).
